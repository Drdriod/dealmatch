# Archived SQL (historical)

The files in this folder are older, hand-written security and admin scripts. They are **not** part of the migration chain in `supabase/migrations/` and must **not** be run against any database.

Their fixes were superseded by the migrations, most recently `supabase/migrations/20261009000000_security_audit_hardening.sql`. See `docs/security/2026-10-database-audit.md`.
