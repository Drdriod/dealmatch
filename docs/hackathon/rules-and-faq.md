## Rules that bind us
1. Building on an existing startup is allowed, but submission and demo must identify, and only showcase, features built during the event. Unclear contributions can disqualify.
2. Repo must be public. Include every contributor's name, a working 3-minute demo video link, and a working repo link.
3. Must meaningfully use Meta Model API or Meta open-weight models.
4. Avoid: AI medical/mental-health advice, basic RAG apps, simple image analyzers, generic education chatbots, job-application screeners, nutrition coaches, personality analyzers, sports analyzers, anything political or about war.
5. No use of code, data or assets without permission.

## Judging (equal weight, after theme and Meta-usage gate)
Impact, Use of Meta AI tooling, Technical depth and execution, Demo quality. Top 5 per track reach finals. Judges assess video, code and live product.
